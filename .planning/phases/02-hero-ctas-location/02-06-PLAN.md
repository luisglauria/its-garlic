<objective>
Close gap G-02-4: the homepage runs four consecutive sections on the identical charcoal surface —
brand story, Location, FAQ and the footer — with exactly one separator, at the first of three seams.
The debug session proved this is a placement defect, not a paint defect: with the palette repaired,
650px of a single uninterrupted colour value still runs across Location, FAQ and the footer.

Two upstream errors produced it. The UI-SPEC's Color table assigned one surface to all three
sections while citing the brand guide's section-variation rule, so no alternation was available to
implement. And the device that does exist is a black taper on charcoal at 1.35:1, near the threshold
of perceptibility — cloning it to the other seams would likely still not read as distinct blocks.

Purpose: MARCA-05 asks the site's visual language to reflect the brand's real materials, of which
diagonal section shapes are one. A reader should be able to tell where the story ends and the
practical information begins.

Output: one shared separator device, applied at every same-surface seam, salient by a measured
contrast rather than by hope, plus a guard that derives each section's surface from its own source
so a later phase cannot add a fourth charcoal block without one.

Runs after 02-04 because nothing here is observable while every background renders browser-default
white, and after 02-05 because both plans edit `src/app/page.tsx`.

Not a tracer: no new layer or path is introduced; this replaces one existing decorative element with
a shared one and applies it at two more seams.
</objective>
