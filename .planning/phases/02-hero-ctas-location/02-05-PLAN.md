the whole CTA section renders outside the hero after the illustration, so neither CTA is above the
fold. The debug session proved three independently necessary causes — a breakpoint set 250px too

overflow instead of a row.

documents currently require the failing layout, so this plan amends them explicitly rather than
shipping code that silently contradicts them.

width, with a committed guard over the amended contract.

measurable once the type families actually render.
