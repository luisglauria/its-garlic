## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| npm registry → local machine | Third-party package tarballs and their install-time scripts execute with the developer's privileges during `npm install`. |
| developer working tree → git history | Anything written to the root can be committed permanently; a committed secret survives deletion. |
| build output → browser bundle | Any `NEXT_PUBLIC_*` value is inlined into JavaScript served to every visitor. |
