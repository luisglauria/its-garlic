<objective>
Wrap every page in an accessible, mobile-first shell that actually looks like It's Garlic — the
vectorized logo on the brand's dark surface, in the brand's typography, with a working skip link
and semantic landmarks — and write the brand guide that lets Phases 2 through 5 build components
without re-deriving any of it.

Purpose: this is the last piece of the foundation. After it, a Phase 2 developer opens one document
to learn how the brand is applied, and drops a section into a shell that is already keyboard-
navigable, already responsive, and already on-brand.

Output: a shared root layout with header/footer/skip-link components, and
`docs/brand-guidelines.md`.
